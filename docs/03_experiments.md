## Conventions

- Un ID d'expérience (`EXP-XXXX`) n'est jamais réutilisé, même si l'expérience
  est abandonnée.
- Toute expérience doit être rejouable des mois plus tard dans exactement les
  mêmes conditions (config versionnée, seed si applicable, version du code
  utilisée).
