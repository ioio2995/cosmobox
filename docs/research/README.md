# Documents de recherche

Ce dossier contient les documents de travail scientifiques et historiques du projet CosmoBox.

Ils ne constituent pas la spécification stabilisée du modèle. Les éléments retenus doivent ensuite être extraits vers les documents de référence de `docs/` et, lorsqu'une décision est actée, vers un ADR.

## Documents

- [`0000-etat-des-lieux.md`](0000-etat-des-lieux.md) — synthèse initiale des idées, essais, résultats, pistes abandonnées et questions ouvertes avant la reprise formelle du projet.
