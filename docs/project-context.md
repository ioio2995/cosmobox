# Contexte du projet Cosmobox

## Origine

Cosmobox a commencé comme un simulateur classique de maillage diamant/blende déformable. Ce prototype reste utile pour la visualisation, mais il suppose déjà un espace, des coordonnées et une mécanique classique.

## Nouvelle direction

Le programme de recherche actuel étudie un substrat quantique relationnel dans lequel :

- la matière correspond à des excitations locales ;
- une structure de jauge U(1) est portée par les relations entre sites ;
- une métrique effective pourrait être reconstruite à partir des corrélations et de l’intrication ;
- une réponse géométrique collective à l’énergie est recherchée dans une phase ultérieure.

Le réseau n’est pas considéré comme un grillage matériel plongé dans un espace externe. Dans la piste la plus ambitieuse, les relations définissent elles-mêmes la structure spatiale. Cependant, la phase 1 ne tente pas encore de faire émerger la topologie.

## Deux pistes séparées

### Piste A — calculable

- topologie imposée ;
- fermions complexes sur les nœuds ;
- quantum links U(1) sur les arêtes ;
- loi de Gauss exacte ;
- étude d’une métrique et d’une causalité effectives.

### Piste B — exploratoire

- arêtes dynamiques ;
- coût de valence ;
- récompense de cycles courts ;
- recherche d’une phase de dimension spectrale finie.

Les deux pistes ne doivent pas être mélangées au niveau 0.

## Références conceptuelles

Le programme est motivé par plusieurs lignes existantes :

- Jacobson : équation d’Einstein comme équation d’état / équilibre d’intrication ;
- Weinberg–Witten : contrainte sur l’émergence naïve d’un spin 2 sans masse ;
- string-nets : matière et jauge émergentes d’un substrat commun ;
- SYK complexe et réseaux de dots : exemple de dynamique relationnelle fortement corrélée ;
- quantum graphity : précédent pour une topologie relationnelle dynamique.

Ces rapprochements ne constituent pas une preuve que le modèle est correct.

## Objectif du niveau 0

Le niveau 0 ne teste ni la gravité émergente ni l’invariance de Lorentz. Il doit seulement produire un socle exact et vérifiable :

1. géométries finies déterministes ;
2. encodage compact des occupations et flux ;
3. construction exacte du sous-espace physique G_i = 0 ;
4. opérateurs de jauge et fermioniques ;
5. Hamiltonien creux ;
6. tests d’hermiticité, fermeture, conservation et invariance de jauge.

## Non-revendications

À ce stade, Cosmobox ne prétend pas :

- dériver le modèle standard ;
- reproduire la relativité générale ;
- produire un graviton ;
- faire émerger une topologie ;
- établir une théorie nouvelle validée expérimentalement.
