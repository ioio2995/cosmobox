# Architecture / Model Decision Records

Ce dossier contient l'historique des décisions structurantes du projet
(physiques ou logicielles). Une décision significative sans ADR n'a pas eu
lieu.

## Convention de nommage

`XXXX-titre-court-en-kebab-case.md`, numéro à 4 chiffres, jamais réutilisé
même si la décision est rejetée.

## Gabarit

Voir [`0000-template.md`](0000-template.md).

## Statuts possibles

- **Proposée** — en discussion, pas encore appliquée.
- **Acceptée** — appliquée, fait foi.
- **Rejetée** — étudiée puis écartée ; on garde la trace pour ne pas
  redécouvrir les mêmes impasses.
- **À revoir** — acceptée puis remise en question par de nouveaux résultats.
